# Runbooks

One procedure per milestone: a status line with the validation date, inputs and access, numbered steps with exact commands, and the expected result of each. Local values are placeholders. The [reproduce page](../reproduce.md) gives the order.

| Runbook | Covers |
|---|---|
| [Foundations](foundations.md) | Repository protection, the Azure foundation (Foundry resource, project, deployments, storage), the case sources, the prior-knowledge answers, the model re-check |
| [Extraction](extraction.md) | Content Understanding, chart descriptions, the evidence cut, library capture and extraction, answer keys drafted, reviewed, and frozen |
| [Retrieval](retrieval.md) | The pinned extraction model, the search service, the index build and its size, the gate, the service's deletion |
| [Investigator](investigator.md) | The evidence check, the safety role, an investigation, its result, a challenge, its trace, the agents' removal, a scored run on the page |
| [Sealing](sealing.md) | Choosing and registering outages without a published cause, sealing, revealing, dropping, removing the agents |
| [Evaluation](evaluation.md) | Freezing the rubric and labels, library snapshots, injection tests, scored runs, the Foundry cloud evaluation, the judge, review and scores, clean-up |
| [Deployment](deployment.md) | The full environment from one template: preview, provision, image, data load, signed-in page, traces, Foundry IQ comparison, removal |
| [Teardown](teardown.md) | The checks before deletion, and the removal of the hand-built resources |
| [Local development](development.md) | The checks CI runs, the configuration, the test-data requirements |
